# Coffee Shop Management Website

## Giới thiệu

Coffee Shop Management Website là hệ thống quản lý và bán đồ uống trực tuyến được xây dựng bằng PHP và MySQL.

Hệ thống hỗ trợ:

- Đăng ký tài khoản
- Đăng nhập
- Quản lý sản phẩm
- Đặt hàng
- Quản lý khách hàng
- Quản lý đơn hàng
- Trang quản trị Admin

## Công nghệ sử dụng

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- phpMyAdmin

## Chức năng chính

### Người dùng
